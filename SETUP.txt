=====================================
  KHADAMNI — Setup Guide
=====================================


PREREQUISITES
=============
Make sure these are installed on your machine:

  1. Python 3.11+       https://www.python.org/downloads/
     (check "Add Python to PATH" during install)

  2. Node.js 18+        https://nodejs.org/  (choose LTS)

  3. MongoDB 6+         https://www.mongodb.com/try/download/community
     Also install MongoDB Compass (offered during the same setup)

  4. Git                https://git-scm.com/downloads


STEP 1 — CLONE THE PROJECT
===========================

  git clone https://github.com/bilelsdn21/khadamni.git
  cd khadamni


STEP 2 — BACKEND SETUP
=======================

  cd backend

  python -m venv venv

  # Activate the virtual environment:
  Windows CMD:       venv\Scripts\activate
  Windows Git Bash:  source venv/Scripts/activate
  Mac/Linux:         source venv/bin/activate

  pip install -r requirements.txt


STEP 3 — CREATE .env FILE
==========================

Inside the backend/ folder, create a file named exactly: .env

  MONGODB_URL=mongodb://localhost:27017
  DATABASE_NAME=khadamni
  SECRET_KEY=replace_with_any_long_random_string
  ALGORITHM=HS256
  ACCESS_TOKEN_EXPIRE_MINUTES=30
  MAIL_USERNAME=your_gmail@gmail.com
  MAIL_PASSWORD=your_gmail_app_password_16_chars
  MAIL_FROM=your_gmail@gmail.com
  MAIL_SERVER=smtp.gmail.com
  MAIL_PORT=587
  GROQ_API_KEY=your_groq_api_key

HOW TO GET A GMAIL APP PASSWORD:
  1. Go to myaccount.google.com → Security
  2. Enable 2-Step Verification
  3. Search "App Passwords" → create one for Mail
  4. Copy the 16-character password → paste as MAIL_PASSWORD

HOW TO GET A GROQ API KEY:
  1. Go to https://console.groq.com
  2. Sign up (free)
  3. Create an API key → paste as GROQ_API_KEY


STEP 4 — START THE BACKEND
===========================

  (make sure venv is active and you are in the backend/ folder)

  uvicorn app.main:app --reload

  You should see: INFO: Uvicorn running on http://127.0.0.1:8000
  API docs:       http://localhost:8000/docs
  Health check:   http://localhost:8000/api/health


STEP 5 — FRONTEND SETUP
========================

Open a NEW terminal (keep the backend running):

  cd frontend
  npm install
  npm run dev

  Open: http://localhost:5173


EVERY TIME YOU RUN THE PROJECT
===============================

You need TWO terminals open simultaneously:

  Terminal 1 — Backend:
    cd backend
    venv\Scripts\activate
    uvicorn app.main:app --reload

  Terminal 2 — Frontend:
    cd frontend
    npm run dev

  Then open: http://localhost:5173


CREATING A MODERATOR ACCOUNT
=============================

1. Register a normal account at /register (any role)
2. Open MongoDB Compass → connect to mongodb://localhost:27017
3. Open the khadamni database → users collection
4. Find the account you just created
5. Edit the document: set  role: "moderator"
6. Log in — you will be redirected to the Moderator Dashboard

  OR use a test account (bypasses OTP):
  Register with an email ending in @test.com
  Then update the role in MongoDB Compass as above.


PROJECT STRUCTURE
=================

khadamni/
  backend/
    app/
      main.py          FastAPI entry point, CORS, router registration
      config.py        Loads .env variables
      database.py      MongoDB async connection (Motor)
      dependencies.py  get_current_user() JWT dependency
      models/          Pydantic schemas (user, request, chat, etc.)

                       chat, profile, portfolio, ratings, ai, moderator)
      services/        Business logic per domain
      utils/           security.py, email.py, validators.py
      websockets/      ConnectionManager for real-time chat + GPS
    uploads/           Stored avatar and portfolio images
    requirements.txt
    seed.py            Optional: seed test data

  frontend/
    src/
      pages/           Login, Register, Map, Profile, Requests,
                       ChatPage, TrackingPage, ModeratorDashboard
      components/      SideDrawer, FloatingChat, ProtectedRoute,
                       NotificationBell, PortfolioGrid, etc.
      context/         AuthContext, ThemeContext
      hooks/           useAuth, useNotifications
      api/             axios.js, auth.js, request.js, chat.js,
                       profile.js, portfolio.js, ratings.js
      layouts/         AuthLayout


TECH STACK
==========

Frontend:   React 19 + Vite + Tailwind CSS v4
Backend:    FastAPI (Python 3) + Motor (async MongoDB driver)
Database:   MongoDB 6  (10 collections, 2dsphere geospatial index)
Auth:       JWT (HS256) + bcrypt + 6-digit OTP + trusted device tokens
Real-time:  FastAPI WebSocket (chat, GPS tracking, price negotiation)
Maps:       Leaflet + react-leaflet + OpenStreetMap tiles
Geocoding:  Nominatim (OpenStreetMap) — proxied through backend
Routing:    OSRM (Open Source Routing Machine) — driving routes
AI:         Groq cloud inference — Llama 3.3-70B
Email:      fastapi-mail + Gmail SMTP


TROUBLESHOOTING
===============

"ModuleNotFoundError" in backend
  → Activate venv first: venv\Scripts\activate
  → Then: pip install -r requirements.txt

"Cannot connect to MongoDB"
  → MongoDB is not running
  → Search "MongoDB" in Windows Start menu and start the service
  → Or install it from https://www.mongodb.com/try/download/community

"AI features not working"
  → Check your GROQ_API_KEY in .env
  → Get a free key at https://console.groq.com

Email OTP not arriving
  → Check MAIL_PASSWORD is the App Password (16 chars, no spaces)
  → Make sure 2-Step Verification is enabled on your Gmail account

CORS error in browser
  → Make sure backend is running on port 8000
  → Make sure frontend is running on port 5173
  → Both must be running at the same time

Port already in use
  → Backend: find and kill the process using port 8000
  → Frontend: kill node.exe in Task Manager, then npm run dev again
