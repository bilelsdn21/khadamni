================================================================
KHADAMNI — HOW TO RUN THE PROJECT (BEGINNER GUIDE)
================================================================

WHAT YOU NEED TO INSTALL FIRST (do this once)
----------------------------------------------------------------

1. Install Python 3.11
   Download from: https://www.python.org/downloads/
   !! IMPORTANT: During installation, check the box that says
   "Add Python to PATH" before clicking Install

2. Install Node.js
   Download from: https://nodejs.org/
   Choose the LTS version (the one that says "Recommended")

3. Install MongoDB Community Server
   Download from: https://www.mongodb.com/try/download/community
   During installation, also install "MongoDB Compass" (it's offered
   during the same setup) — this lets you see your database visually
   After installation, MongoDB runs automatically in the background


================================================================
STEP 1 — SET UP THE BACKEND
================================================================

Open a terminal (Command Prompt or PowerShell) and run these
commands one by one:

   cd path\to\khadamni\backend

   python -m venv venv

   venv\Scripts\activate

   (you should now see "(venv)" at the start of the line)

   pip install -r requirements.txt

   pip install disposable-email-domains


----------------------------------------------------------------
CREATE THE .env FILE
----------------------------------------------------------------

Inside the backend folder, create a file called exactly:  .env
(just dot env, no other name)

Paste this inside it and fill in your values:

   DATABASE_NAME=khadamni
   MONGODB_URL=mongodb://localhost:27017
   SECRET_KEY=any_random_long_string_you_make_up
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=30
   MAIL_USERNAME=your_gmail_address@gmail.com
   MAIL_PASSWORD=your_gmail_app_password
   MAIL_FROM=your_gmail_address@gmail.com
   MAIL_SERVER=smtp.gmail.com
   MAIL_PORT=587

!! HOW TO GET A GMAIL APP PASSWORD:
   1. Go to your Google Account settings
   2. Search for "App Passwords"
   3. Create a new app password for "Mail"
   4. Copy the 16-character password and paste it as MAIL_PASSWORD
   (This only works if you have 2-Step Verification enabled on Gmail)


----------------------------------------------------------------
START THE BACKEND
----------------------------------------------------------------

Make sure you are inside the backend folder with (venv) active,
then run:

   venv\Scripts\uvicorn app.main:app --reload

You should see:
   INFO: Uvicorn running on http://127.0.0.1:8000

Leave this terminal open. The backend is now running.
You can visit http://localhost:8000/docs to see all API endpoints.


================================================================
STEP 2 — SET UP THE FRONTEND
================================================================

Open a NEW terminal window and run:

   cd path\to\khadamni\frontend

   npm install

   npm run dev

You should see:
   Local: http://localhost:5173/

Open that link in your browser. The app is now running.


================================================================
EVERY TIME YOU WANT TO RUN THE PROJECT
================================================================

You need TWO terminals open at the same time:

TERMINAL 1 — Backend:
   cd backend
   venv\Scripts\activate
   venv\Scripts\uvicorn app.main:app --reload
 
TERMINAL 2 — Frontend:
   cd frontend
   npm run dev

Then open http://localhost:5173/ in your browser.


================================================================
COMMON PROBLEMS
================================================================

"ModuleNotFoundError" in backend
   → You forgot to activate the venv or run pip install
   → Run: venv\Scripts\activate then pip install -r requirements.txt

"Registration failed" or 500 error
   → Make sure the backend terminal is running
   → Make sure MongoDB is running (check Task Manager for mongod.exe)
   → Make sure your .env file exists and has the correct values

Port already in use (frontend)
   → Open Task Manager, find all node.exe, end all of them
   → Then run npm run dev again

"Cannot connect to MongoDB"
   → MongoDB is not running
   → Search for "MongoDB" in your Windows Start menu and start it
   → Or restart your computer (MongoDB starts automatically on boot)
