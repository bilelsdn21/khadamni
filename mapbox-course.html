Why "auto-detect" might be wrong
On a desktop PC with ethernet, the browser uses your IP address to guess your location — this can be off by hundreds of km or even show a different country. "Click on map" is the most reliable option on desktop. On a phone, auto-detect uses GPS and is accurate to ~10 meters.
Basics

Lesson 1: Create a Map

The foundation — initializing a Leaflet map on a page. This is the first thing that happens when a client opens Khadamni.

What you're learning
L.map() creates a map instance. You give it a container ID, then call setView([lat, lng], zoom). Unlike Mapbox, Leaflet uses [latitude, longitude] order. Then you add a tile layer — the images that make up the map (from OpenStreetMap, free). 
// 1. Create the map (no token needed!)
const map = L.map('map').setView(
    [36.7538, 3.0588],  // Algiers [lat, lng]
    14                    // Zoom level
);

// 2. Add the tile layer (the actual map images)
L.tileLayer(
    'https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png',
    { attribution: '© OpenStreetMap' }
).addTo(map);
Leaflet vs Mapbox: coordinate order
Leaflet = [latitude, longitude] (like Google Maps)
Mapbox = [longitude, latitude]
Algiers: Leaflet uses [36.7538, 3.0588]

Lesson 2: Map Controls & Dark Theme

Leaflet comes with zoom controls by default. We can also switch to a dark-themed tile layer for a modern look.

// Dark theme tile layer (free, from CartoDB)
L.tileLayer(
    'https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png',
    { attribution: '© CartoDB' }
).addTo(map);

// Zoom control is added by default
// But you can reposition it:
L.control.zoom({
    position: 'topright'
}).addTo(map);

// Add scale bar
L.control.scale().addTo(map);
Free tile providers
OpenStreetMap is just one option. You can also use:
• CartoDB Dark — dark theme (great for Khadamni)
• CartoDB Voyager — clean, modern look
• Stamen Terrain — terrain/topographic
All free, no account needed!

Lesson 3: Get User's Location

In Khadamni, the client sees their own position on the map (the blue pulsing dot). Leaflet has a built-in locate() method, or we use the browser API directly.

// Method 1: Leaflet's built-in locate
map.locate({
    setView: true,         // Move map to user
    maxZoom: 16,
    watch: true            // Keep tracking
});

// When location is found:
map.on('locationfound', (e) => {
    console.log(`Found: ${e.latlng.lat}, ${e.latlng.lng}`);
});

// Method 2: Browser Geolocation API (more control)
navigator.geolocation.getCurrentPosition((pos) => {
    const lat = pos.coords.latitude;
    const lng = pos.coords.longitude;
    console.log(`User at: ${lat}, ${lng}`);
});
In Khadamni
We'll use the browser API for more control. The pulsing blue dot is a custom divIcon marker placed at the user's coordinates. We update it as the user moves.
Markers

Lesson 4: Add Basic Markers

Markers represent service providers on the map. Let's start simple.

// Simplest marker: default icon
L.marker([36.7538, 3.0588]).addTo(map);

// Marker from data (like from your API)
const providers = [
    { name: "Ahmed", lat: 36.752, lng: 3.055 },
    { name: "Sara",  lat: 36.758, lng: 3.062 },
];

providers.forEach(p => {
    L.marker([p.lat, p.lng])
        .addTo(map);
});
Key pattern
In Khadamni, providers come from your FastAPI backend. You fetch them, loop through, and create a marker for each. The pattern is always: L.marker([lat, lng]).addTo(map).
Markers

Lesson 5: Custom Markers (per service category)

In Khadamni, each service type has its own icon. We use Leaflet's divIcon to create custom HTML markers.

// Icons per category
const icons = {
    plumber: "🔧",
    electrician: "⚡",
    cleaner: "🧹",
};

providers.forEach(p => {
    // Create a custom icon using HTML
    const icon = L.divIcon({
        className: '',  // Remove default styles
        html: `<div class="custom-marker marker-${p.category}">
                ${icons[p.category]}
                <div class="ready-badge"></div>
              </div>`,
        iconSize: [40, 40],      // Size of the icon
        iconAnchor: [20, 20],    // Center point
        popupAnchor: [0, -20],   // Popup position
    });

    L.marker([p.lat, p.lng], { icon: icon })
        .addTo(map);
});
L.divIcon — the key to custom markers
divIcon lets you use any HTML/CSS as a marker. This is how we get category-specific colored circles with emoji icons and green "ready" badges. Same power as Mapbox custom elements.

Lesson 6: Popups (click a marker to see info)

When a client clicks a provider marker, a popup shows their mini-profile with a "Send Request" button.

providers.forEach(p => {
    const icon = /* ... divIcon ... */
    const dist = getDistanceKm(/* ... */);

    // Create popup HTML
    const popupHtml = `
        <div class="popup-name">${p.name}</div>
        <div class="popup-category">${p.category}</div>
        <div class="popup-rating">★ ${p.rating}</div>
        <div class="popup-distance">${dist} km away</div>
        <button class="popup-btn">Send Request</button>
    `;

    L.marker([p.lat, p.lng], { icon })
        .bindPopup(popupHtml)   // Attach popup
        .addTo(map);
});
bindPopup vs setPopup
In Leaflet: marker.bindPopup(html) attaches a popup that opens on click.
You can also use marker.bindTooltip(text) for hover tooltips.
The popup content is just HTML — you can put anything in it.

Lesson 7: Filter Markers by Category

Show only plumbers, only electricians, etc. We use Leaflet LayerGroups to manage sets of markers.

// Create a layer group for each category
const layers = {
    plumber: L.layerGroup().addTo(map),
    electrician: L.layerGroup().addTo(map),
    cleaner: L.layerGroup().addTo(map),
};

// Add markers to their category layer
providers.forEach(p => {
    const marker = L.marker([p.lat, p.lng], { icon });
    marker.addTo(layers[p.category]);
});

// Filter: show only plumbers
function filterByCategory(category) {
    Object.entries(layers).forEach(([cat, layer]) => {
        if (category === 'all' || cat === category) {
            map.addLayer(layer);     // Show
        } else {
            map.removeLayer(layer);  // Hide
        }
    });
}
LayerGroup — Leaflet's way to group markers
Instead of tracking individual markers in an array, Leaflet has LayerGroup. Add markers to a group, then show/hide the entire group at once. Cleaner and more efficient.

Lesson 8: Load Providers When Map Moves

Don't load ALL providers at once. Load only what's visible. When the user pans/zooms, fetch new data from the API.

// Listen for map movement
map.on('moveend', () => {
    // Get visible area boundaries
    const bounds = map.getBounds();

    // Southwest corner (bottom-left)
    const sw = bounds.getSouthWest();
    // Northeast corner (top-right)
    const ne = bounds.getNorthEast();

    console.log(`SW: [${sw.lat}, ${sw.lng}]`);
    console.log(`NE: [${ne.lat}, ${ne.lng}]`);

    // In real app: fetch from FastAPI
    // fetch(`/api/map/providers?
    //   sw_lat=${sw.lat}&sw_lng=${sw.lng}
    //   &ne_lat=${ne.lat}&ne_lng=${ne.lng}`)
});
Identical concept to Mapbox
The getBounds() method works the same way. You get the visible rectangle and send it to your backend. MongoDB's $geoWithin returns only providers in that area. The only difference: Leaflet bounds use .lat/.lng properties.
Real-time

Lesson 9: Distance Between Two Points

Calculate the distance between client and provider. Leaflet has a built-in method for this!

// Leaflet has distance built-in!
const clientPos = L.latLng(36.7538, 3.0588);
const providerPos = L.latLng(36.7600, 3.0500);

// Distance in meters (built-in!)
const meters = clientPos.distanceTo(providerPos);
const km = meters / 1000;

console.log(`Distance: ${km.toFixed(2)} km`);
console.log(`Distance: ${meters.toFixed(0)} meters`);

// No Haversine formula needed!
// Leaflet does it for you internally.
Advantage over Mapbox
Leaflet has distanceTo() built-in! No need to write the Haversine formula yourself. Create two L.latLng objects and call .distanceTo(). Returns meters. Divide by 1000 for km.

Lesson 10: Moving Markers (Live Tracking)

The core of Khadamni's tracking: a provider marker that moves in real-time as they approach the client.

// Create a marker with custom icon
const providerMarker = L.marker(
    [providerLat, providerLng],
    { icon: myIcon }
).addTo(map);

// Move it (called when WebSocket sends new location)
function updateLocation(newLat, newLng) {
    providerMarker.setLatLng([newLat, newLng]);
}

// In real app, WebSocket sends updates:
// ws.onmessage = (event) => {
//   const data = JSON.parse(event.data);
//   updateLocation(data.lat, data.lng);

setLatLng — the key method
marker.setLatLng([lat, lng]) moves the marker instantly. Called every time the WebSocket receives a new GPS position from the provider's phone. The map updates in real-time.
Advanced

Lesson 11: Draw a Route Line Between Two Points

During tracking, draw a dashed line connecting client and provider on the map.

// Create a polyline (line on the map)
const routeLine = L.polyline(
    [ clientLatLng, providerLatLng ],
    {
        color: '#3b82f6',
        weight: 3,
        dashArray: '10, 8',       // Dashed line
        opacity: 0.8
    }
).addTo(map);

// Update line when positions change
function updateRoute(clientPos, providerPos) {
    routeLine.setLatLngs([clientPos, providerPos]);
}

// Fit map to show both points
map.fitBounds(routeLine.getBounds(), {
    padding: [50, 50]
});
Simpler than Mapbox!
In Mapbox you need a GeoJSON source + layer. In Leaflet it's just L.polyline() — pass an array of coordinates and style options. Update with .setLatLngs(). Much simpler.
