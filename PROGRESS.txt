2. COMPLETED FEATURES
----------------------------------------------------------------

[BACKEND]

✅ MongoDB Connection
   - Async connection using Motor driver
   - Connect on server startup, disconnect on shutdown (lifespan)
   - Database name loaded from .env

✅ User Registration (POST /api/auth/register)
   - Accepts: first_name, last_name, email, password, role, phone, location
   - Rejects disposable/temporary email addresses
   - Blocks duplicate email registrations
   - Hashes passwords with bcrypt before storing
   - Validates provider-required fields: bio, service_categories, experience_years
   - Auto-creates a provider_profile document for provider accounts
   - Returns created user (without password)

✅ User Login with Email OTP (POST /api/auth/login)
   - Verifies email and password credentials
   - On success: generates a 6-digit OTP, saves to otp_codes collection with 5-minute expiry
   - Sends OTP to user's email via Gmail SMTP
   - Does NOT return JWT token yet — waits for OTP verification

✅ OTP Verification (POST /api/auth/verify-otp)
   - Accepts: email + 6-digit code
   - Checks code exists and has not expired
   - Deletes code after use (one-time use only)
   - Returns JWT access token + user data on success
   - Returns appropriate errors for invalid or expired codes

✅ JWT Token System
   - Tokens signed with HS256 algorithm
   - Configurable expiry via ACCESS_TOKEN_EXPIRE_MINUTES
   - Tokens carry user ID as subject claim

✅ Temp Mail Detection
   - Uses disposable-email-domains package (offline, no API needed)
   - Blocks thousands of known disposable domains (mailinator, guerrillamail, etc.)
   - Checked at registration before anything else

[FRONTEND]

✅ Home Page
   - Split layout matching original design
   - Left panel: logo, navigation, headline, CTA buttons
   - Right panel: service icons orbiting around CLIENT hub

✅ Register Page
   - White/blue theme consistent with Home page
   - Role selection (Client / Provider)
   - Provider-specific fields appear dynamically: bio, service categories (clickable pills),
     experience years, hourly rate
   - Error handling for temp mail and missing provider fields
   - Connected to POST /api/auth/register

✅ Login Page (Two-Step)
   - Step 1: Email + password form
   - Step 2: OTP input screen (shown after successful credential check)
   - Displays the email the code was sent to
   - "Go back" link if user didn't receive the code
   - Connected to POST /api/auth/login and POST /api/auth/verify-otp

✅ Auth State Management
   - AuthContext stores user data and token globally
   - JWT token saved to localStorage on successful OTP verification
   - Token automatically attached to all future API requests (axios interceptor)
   - useAuth() hook used across pages to access login/logout/user

✅ Routing
   - / → Home page
   - /login → Login page
   - /register → Register page
   - Auth pages share a consistent AuthLayout

3. TECHNICAL DECISIONS
----------------------------------------------------------------

- FastAPI chosen for async support and automatic API documentation (/docs)
- MongoDB chosen for flexible schema (different fields for clients vs providers)
- Motor used instead of PyMongo for async database operations
- bcrypt used for password hashing (industry standard)
- JWT tokens used for stateless authentication (no server-side sessions)
- Email OTP chosen over SMS OTP (free, no third-party service cost)
- Gmail SMTP used for email delivery (free, 500 emails/day)
- disposable-email-domains used offline to block temp emails (no API limits)
- Axios interceptor auto-attaches token to every request (no manual work per call)
- Provider profile stored in a separate collection for clean map queries

4. DATABASE COLLECTIONS
----------------------------------------------------------------

provider_profiles — extended profiles for provider accounts
otp_codes         — temporary OTP records (expire after 5 minutes)

7. HOW TO RUN LOCALLY
----------------------------------------------------------------

BACKEND:
  cd backend
  venv\Scripts\activate         (Windows CMD)
  uvicorn app.main:app --reload
  API docs: http://localhost:8000/docs

FRONTEND:
  cd frontend
  npm install
  npm run dev
  App: http://localhost:5173

REQUIREMENTS:
  - Python 3.11+
  - Node.js 18+
  - MongoDB running on localhost:27017
  - Gmail App Password configured in .env
