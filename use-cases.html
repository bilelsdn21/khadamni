Use Case Descriptions Reference

Detailed description of each use case.

ID Use Case Actor(s) Description
UC-01 Register & Authenticate Client, Provider, Moderator Create an account (client/provider), verify email, log in, reset password, and log out. Moderator uses pre-assigned credentials.
UC-02 Browse Map Client View an interactive map showing nearby available service providers with real-time position updates.
UC-03 Search & Filter Providers Client Filter providers displayed on the map by service category and proximity radius.
UC-04 View Provider Profile Client Access a provider's full profile including bio, portfolio, ratings, and reviews.
UC-05 Send Service Request Client Submit a service request to a selected provider with a description and optional proposed price.
UC-06 Manage Profile & Portfolio Provider Create and edit profile information (bio, categories, hourly rate) and upload portfolio items.
UC-07 Toggle Availability Provider Set availability status to ready (visible on map) or not ready (hidden from map).
UC-08 Handle Requests Provider Receive, view, accept, or reject incoming service requests from clients.
UC-09 Chat & Negotiate Client, Provider Communicate through a private real-time chat room to negotiate price, scope, and schedule.
UC-10 Live Location Tracking Client, Provider Track the other party's live GPS position on the map during an active job.
UC-11 Complete & Review Job Client, Provider Both parties confirm job completion and submit a mutual rating and review.
UC-12 Receive Notifications Client, Provider Receive real-time notifications for request updates, new messages, and job events.
UC-13 View Job History Client, Provider Browse past jobs with filtering options and view performance statistics.
UC-14 Manage Users Moderator View, suspend, reactivate, and delete user accounts on the platform.
UC-15 Handle Reports Moderator Review and process reports submitted by users regarding disputes or violations.
UC-16 Manage Categories Moderator Add, edit, and remove service categories available on the platform.
UC-17 View Statistics Moderator Access platform-wide statistics including total users, active jobs, and completed jobs.
